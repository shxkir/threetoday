# Publish checklist — AWS Builder Center

## Before you publish

1. [ ] AWS account verification complete (Lambda works)
2. [ ] Deployed: `./infra/deploy-cli.sh` (or watch-and-deploy finished)
3. [ ] Live URL works — **Load sample** → **Lock my three** returns AI plan
4. [ ] Paste Function URL into `ARTICLE.md` (replace `PASTE_YOUR_FUNCTION_URL_HERE`)
5. [ ] Take 2–3 screenshots: empty form, sample dump, locked three + schedule
6. [ ] Word count ≥ 500 (draft is already ~1100+)

## Builder Center article settings

| Field | Value |
| --- | --- |
| **Title** | `Weekend Productivity Challenge: ThreeToday` |
| **Tag** | `#productivity` |
| **Body** | Paste from `ARTICLE.md` (skip the top “Publish this…” meta box if you want) |

## Where to publish

1. Go to https://builder.aws.com and sign in  
2. Create new **Article**  
3. Paste content, add tag, add screenshots  
4. **Publish before July 13, 2026 — 1:00 PM PT**

## Qualify rules (pass/fail)

1. Completeness — 500+ words, all sections, working link  
2. Relevance — real AI productivity tool that works  
3. AWS usage — at least one service, clearly described  

First **50** that pass get the AWS Builder Jacket.
